# WasteViT project work

This repository keeps each weekly experiment independent and reproducible.

## Project folders

| Folder | Purpose |
|---|---|
| [`projects/01_zerowaste_s_self_supervised_simclr_mlflow`](projects/01_zerowaste_s_self_supervised_simclr_mlflow) | Self-supervised SimCLR training on unlabeled ZeroWaste-s conveyor-belt images, with MLflow experiment tracking |
| [`projects/02_trashnet_vit_unsupervised_finetuning`](projects/02_trashnet_vit_unsupervised_finetuning) | DINOv2 and MAE frozen-feature evaluation followed by label-free unsupervised fine-tuning on TrashNet |

Start with the README inside the relevant project folder. Datasets, checkpoints,
MLflow databases, generated reports, and private project documents are excluded
from Git because they are either large, reproducible, or confidential.
