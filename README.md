# WasteViT project work

This repository keeps each weekly experiment independent and reproducible.

## Project folders

| Folder | Purpose |
|---|---|
| [`projects/01_ssl_domain_adaptation`](projects/01_ssl_domain_adaptation) | Previous SimCLR domain-adaptation work on waste imagery |
| [`projects/02_trashnet_vit`](projects/02_trashnet_vit) | Current Vision Transformer pipeline for TrashNet: frozen baseline, self-supervised adaptation, and supervised fine-tuning |

Start with the README inside the relevant project folder. Datasets, checkpoints,
MLflow databases, generated reports, and private project documents are excluded
from Git because they are either large, reproducible, or confidential.
